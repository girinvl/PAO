Краткая инструкция отдельно для десктопа и мобильных устройств.

💻 Десктопная версия

Навигация

←→ — холодильники, ↑↓ — полки и тела, Enter — открыть, Space — взять / положить тело.

Работа с телами

  • Клик по пустой полке — создать запись.
  • Клик по телу — открыть редактирование.
  • Drag & Drop мышью — перенести тело на другую полку.
  • Через клавиатуру: выделить тело → Space → перейти на полку → Space.

Горячие клавиши

1 не вскрыт, 2 вскрыт, V голосовой код, L голосовой рост, Esc закрыть форму.

Горячие клавиши действуют на тело в рамке выделения.

Значки и статусы

🧸 Толстый — специальная пометка, выводится рядом с ростом.
🔵 Синий — специальная пометка.
🦵 Кривой — специальная пометка.
🌿 Растительность — специальная пометка.
⚠️ Дефекты — специальная пометка.
🔔 Есть комментарий.
❗ Дубликат фамилии.
💩 Старая запись / требует внимания.

Без места / на полу

Используется для тел без размещения, временно находящихся на полу или ожидающих свободную полку.

📱 Мобильная версия

Основные действия

  • ☰ — открыть меню.
  • Тап по телу — открыть карточку.
  • Тап по пустой полке — создать запись.
  • Двойной тап по телу — сменить статус вскрытия.
  • Долгое удержание — начать перенос тела.

Перенос и прокрутка

  1. Зажмите тело долгим удержанием.
  2. Перетащите его к нужной полке.
  3. Если полка ниже или выше — подведите палец к краю экрана.
  4. Страница начнёт прокручиваться автоматически.
  5. Отпустите тело над нужной полкой.

Форма на телефоне

  • Голосовая запись не запускается сама — нажмите кнопку 🎤 Запись.
  • У каждого поля есть × для быстрой очистки.
  • Инициалы автоматически становятся большими буквами.
  • Фамилия автоматически начинается с большой буквы.
  • Пометки 🧸 🔵 🦵 🌿 ⚠️ включаются прямо в форме.

Если неудобно в перчатках

Используйте длинное удержание вместо быстрых жестов. Если перенос начался случайно — отпустите палец и повторите удержание.
